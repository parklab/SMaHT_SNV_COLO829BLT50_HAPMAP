# Cross-sample artifact filtering workflow for short-read variant calls

To mitigate recurrent, alignment-driven false positive SNVs enriched in difficult and extreme genomic regions, we implemented a cross-sample pileup filtering workflow using an independent control sample. For candidate variants, we generated targeted pileups at variant loci using `bcftools mpileup` (v1.21; minimum base and mapping quality Q20, depth capped at 3000, excluding secondary and duplicate reads). Pileups were normalized (`bcftools norm`) and restricted to candidate sites.
Variants were retained only if supported by >1 alternate read in the target sample and ≤1 alternate read in the independent control sample. This allele depth–based criterion suppresses recurrent low-level sequencing and alignment artifacts observed across datasets while preserving true positives. 



**This pipeline:**
- Generates pileups at candidate variant sites
- Performs parallel mpileup + normalization
- Filters variants based on AD support in target vs control
- Outputs a final filtered VCF

## Requirements
- Snakemake
- bcftools
- tabix
- GNU parallel
- Python ≥ 3.8
- granite-suite (vcf_parser module)

## Control BAM sample

The pipeline was evaluated using the Illumina ST001-1A SMaHT donor sample as a control. The corresponding ~500X BAM file is available on the SMaHT Data Portal and was generated by merging the following CRAM files with `samtools merge`.

- [SMAFIKG7SLLT](https://data.smaht.org/SMAFIKG7SLLT)
- [SMAFI6T95D8Q](https://data.smaht.org/SMAFI6T95D8Q)
- [SMAFIPAMMHBC](https://data.smaht.org/SMAFIPAMMHBC)
- [SMAFIPAMMHBC](https://data.smaht.org/SMAFIPAMMHBC)

## Overview
The workflow consists of two main rules:

```
rule all
 └── filter
      └── pileup
```

### Step 1 — Pileup (rule pileup)

Extract variant positions from input VCF
Convert to 0-based BED
Split into chunks (default: 1000 regions per chunk)
Run bcftools mpileup in parallel
Normalize each chunk
Concatenate normalized VCFs

Output:
`*_PU_norm.q20.Q20.vcf.gz`

### Step 2 — Filtering (rule filter)

Variants are retained only if:

```
Target AD (alt depth) > 1
AND
Control AD (alt depth) ≤ 1
```
