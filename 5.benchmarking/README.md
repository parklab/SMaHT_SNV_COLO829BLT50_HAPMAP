# 5. Benchmarking of Low-VAF Mosaic Mutation Detection

This directory contains scripts and notebooks used to **evaluate variant-calling pipelines** against the COLO829BLT50 reference mutation set, as part of the SMaHT Network low-VAF (<2%) mosaic mutation detection challenge described in the manuscript *"Detecting low allele fraction mosaic mutations: A multi-institution benchmarking with cell line mixtures."*

## Overview

To assess the effectiveness of current methods for low-VAF mosaic SNV and indel detection, a Network-wide benchmarking challenge was conducted. Seven institutions contributed **twelve variant-calling pipelines** (mSNVs and mIndels), applied to single-sample Illumina WGS data from the COLO829BLT50 mixture, which contains mosaic mutations at VAFs below 2%.

Five biological replicates of the mixture were sequenced at depths ranging from **170× to 470×**, representing real-world whole-genome data with biological and technical variability. Five additional *in silico* COLO829BLT50 datasets were generated by mixing BAM files of the parental cell lines at defined depths (100×–500×), enabling controlled evaluation of depth-dependent performance. Because the analyses were limited to datasets with depths up to 500×, the truth set was restricted to variants theoretically observable at this depth: **39,389 SNVs and 2,059 indels**.

Each call set was compared against:

- **Positive control (reference set)** — validated mosaic variants from [`2.truthset_pacbio_validation`](../2.truthset_pacbio_validation).
- **Negative control** — reference-homozygous sites from [`3.negative_control`](../3.negative_control).
- **Masked (ambiguous) sites** — excluded from evaluation.

Performance was reported in terms of sensitivity, precision, and F1 score stratified by VAF bin, sequencing depth, and genomic region (easy / difficult / extreme).

## Files

- **`Annotate.sh`** — Shell pipeline that annotates each submitted call set against the reference mutation set, negative-control BED regions, and a germline VCF (COLO829BL). It intersects candidate VCFs with BED files per genomic region and prepares the annotated inputs consumed by the evaluation notebook.
- **`Evaluation_challenge.ipynb`** — Jupyter notebook that computes per-pipeline benchmarking metrics (sensitivity, precision, F1) across VAF bins and sequencing depths, and generates the figures comparing the twelve participating pipelines (Fig. 4 in the manuscript). It also stratifies performance by genomic context (easy / difficult / extreme) using the region definitions in [`Resource`](../Resource).

## Workflow Summary

1. Collect VCF submissions from each participating pipeline applied to the five biological (and *in silico*) COLO829BLT50 datasets.
2. Run `Annotate.sh` to cross-reference each call set with the positive reference set, the negative-control set, and the germline VCF, producing annotated call sets ready for evaluation.
3. Execute `Evaluation_challenge.ipynb` to compute sensitivity, precision, and F1 scores per VAF bin, per sequencing depth, and per genomic region, and to render the benchmarking figures.

## Key Findings (summary)

- At **170×**, sensitivity of mSNVs was uniformly poor, with only a few pipelines reaching ~50% in the 2–3% VAF bin.
- At **390× and higher**, nearly half of the methods exceeded 70% sensitivity, with MosaicForecast (M12), Broad Mutect2 (M4), UW-SCRI Mutect2 (M8), and RUFUS with matched control (M9–M11) performing best.
- For >2% VAF SNVs, sensitivity and precision approached ~80% at ≥300×, with little additional gain from deeper sequencing.
- For ultra-low-VAF **indels**, sensitivity remained low (~15% even with RUFUS + matched control at 470×), reflecting the inherent mapping challenges of short reads spanning insertions or deletions.
- True-positive and false-positive sets differed substantially across pipelines, suggesting that simple intersection of multiple callers reduces false positives at the cost of discarding many true variants.
